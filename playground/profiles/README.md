# Contributed persona groups

Persona groups saved from the HumanStudy-Hub playground, named
`<study>-<contributor>-<n>.json`. The number rises each time the same
contributor saves another group for the same study, so nothing is replaced.

A group describes a population rather than a fixed cast: each segment carries a
share of the participants and the ranges its members are drawn from, so any
group here fits a run of any size. See [../README.md](../README.md#personas) for
the format, and `playground/personas.py` for the sampler.

Anyone can reuse a group here by loading it in the playground's persona
designer.
