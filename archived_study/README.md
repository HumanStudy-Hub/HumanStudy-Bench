# Archived Studies

This directory preserves complete study packages that are not active benchmark
or extension candidates. Archived packages remain directly runnable for audit
and comparison, but they are excluded from `studies/` and the website index.

Archived packages:

- `study_018`: Molleman et al. (2020), archived because the target task depends
  on controlled six-second visual exposure and browser interaction.

Incomplete screening runs, parser caches, and packages whose readiness audit
failed are not retained. A Stage 4 package with runnable materials but only a
placeholder evaluator is also treated as incomplete.
